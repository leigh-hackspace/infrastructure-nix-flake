# The 4 KiB physical pages this box has been *measured* corrupting.
#
# Format: one page frame per line, hex, sorted, field 1 is what the tooling reads;
# the comment on each line is the first byte of that page.  Blank lines and `#`
# lines are comments, and field 1 must stay parseable: ./bad-ram.nix reads it twice.
# At evaluation time it derives the floor `infra.badRam.cap` is asserted against (the
# cap must stay below the lowest frame here); at boot, `bad-ram-cap-check.service`
# compares that same lowest frame against the top of /proc/iomem's System RAM.  So this
# file is the single fact behind both halves of the guard, and neither half repeats a
# number from it by hand.
#
# Provenance of every line:
#
#   270 of them  stressapptest's own physical frames from the 1 h run of
#                2026-11-21 22:58 (`/var/log/memstress-20261121-2258.log`: 298
#                single-bit `Hardware Error:` lines, every one of them in byte
#                lane 6 of the 8-byte word).  A frame is listed if *any* 8-byte
#                word inside it failed, because a partially-bad page is a bad
#                page: the kernel cannot hand out a fragment of one.
#   0x81b3b5     the frame the kernel named itself on 2026-11-21: `BUG: Bad page
#                state ... pfn 0x81b3b5`, in the Oops that hit seven processes
#                with one identical corrupted pointer.
#   0x81fcba     the frame it named on 2026-11-22: `BUG: Bad page cache ...
#                pfn:81fcba`, from the PTE `800800081fcba867` that three
#                strata processes faulted on at one virtual address.
#
# 272 pages x 4 KiB = 1.0625 MiB, spread over 0x7d5a29000..0x99431f000
# (31.34..38.32 GiB) in 269 runs: 269 of the 272 pages are isolated singletons.
#
# That sparseness is the whole design problem, and it is why this file is *not*
# rendered into `memmap=` boot arguments -- ./bad-ram-fence.nix carries the two
# kernel budgets that refuse ~270 entries and says what fences these pages
# instead.  ./README.md owns the diagnosis; this file is only the receipt.
